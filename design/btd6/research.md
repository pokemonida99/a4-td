# Bloons TD 6 核心機制整理（給改編用，只學機制）

> 用途：準時下班防衛戰要「參考 BTD6 的同事能力與敵人能力」。這份只整理**機制**；名稱、數值、美術都不照抄。改編方案見 `gpt_b1.md` 與 `DESIGN.md`。

## 1. 塔的升級：3 條路線 × 5 階，加上交叉限制
- 每種塔有 3 條升級路線（上／中／下），每條 5 階，越後面越貴（第 5 階常是基本價的 10～30 倍）。
- **交叉限制**：最多只能有**一條**路線升超過 2 階。合法組合例如 5-2-0、0-2-5、2-0-4；5-3-0、3-3-0 都不行。
  - 效果：玩家得「選一個主修方向＋一點副修」，同一種塔可以變成完全不同的定位（例如單體狙擊 vs 範圍爆破）。
- 前幾階通常是數值、範圍、穿透數；**第 3 階常是質變**（多一種傷害類型、看得到隱形、能打鉛）；**第 4 階**常是強力被動；**第 5 階**是終極型態。
- 有些升級會**改變傷害類型**，讓原本打不動某種氣球的塔變得打得動。這是「一種塔要換路線才能處理特定敵人」的核心手段。
- 塔有可選的**索敵方式**：最前面（first）、最後面（last）、最近（close）、最強（strong）。

## 2. 主動技能與冷卻
- 部分 3～5 階升級會解鎖**主動技能**：按一下觸發，然後冷卻 30～90 秒。
- 主動技能的種類：短時間爆發（攻速大增）、全圖傷害、凍結全場、召喚單位、對單一大目標造成巨量傷害、立即賺錢。
- 同種技能多座塔**共用一個按鈕**（按一次觸發一座，冷卻分開）。
- 設計意圖：讓玩家在**特定的危險時刻**（大波、魔王）做出判斷，而不是一直按。

## 3. 傷害類型 vs 氣球屬性（「誰能處理什麼」）
每次攻擊都有傷害類型（尖銳、爆炸、能量、冰凍、火焰、電漿、普通等）。氣球的屬性會讓某些類型無效：

| 氣球屬性 | 機制 | 玩家要做的事 |
|---|---|---|
| **迷彩（Camo）** | 沒有「偵測」的塔**看不到、不能瞄準**它。但範圍爆炸剛好炸到時仍會受傷。 | 帶有偵測的塔或升級、或靠支援塔給周圍偵測（雷達）。 |
| **鉛（Lead）** | 免疫尖銳類（飛鏢、刀刃）。 | 用爆炸、火、能量等打，或靠升級讓尖銳塔能破鉛。 |
| **黑／白（Black / White）** | 黑免疫爆炸、白免疫冰凍；斑馬兩者都免疫。 | 不能只帶一種範圍塔。 |
| **紫（Purple）** | 免疫能量、火、電漿（魔法類）。 | 要有物理類輸出。 |
| **再生（Regrow）** | 沒被打的時候會一層層長回來。 | 要持續輸出，不能讓它慢慢掉、慢慢長。 |
| **加固（Fortified）** | 血量加倍（陶瓷、鉛、MOAB 類可以加固）。 | 後期需要真正的高傷害。 |
| **陶瓷（Ceramic）** | 很厚的外殼，打破後才裂成裡面的小氣球。 | 單體高傷害的需求出現。 |
| **MOAB 級（飛船）** | 血很厚、走得慢，**被打爆時吐出好幾顆子氣球**（子又可能有屬性）。最上級的 DDT 同時是迷彩＋鉛＋黑，而且很快。 | 要有「對大目標」的輸出，還要能接住爆開後的一大群。 |
| **速度** | 粉紅、彩虹、DDT 很快；MOAB 慢。 | 減速、終點附近要有補刀。 |

- 氣球是「**一層包一層**」：打掉一層會變成下一層（紅 < 藍 < 綠 < 黃 < 粉 …），所以一顆大氣球會連續吃很多次攻擊，**穿透數**（一發能打幾顆）很重要。
- 冰凍塔可以讓大量氣球停住，但打不動被凍住的某些類型（設計成需要搭配）。

## 4. 關卡節奏（回合設計）
- 每回合是寫死的敵人表，**新屬性按順序登場**：先教迷彩、再教鉛、再來陶瓷、再來 MOAB。
- 新屬性第一次出現時**只有少量**（教學），之後才大量混編。
- 有幾個「檢查點回合」專門考某種能力（例如一大群迷彩、一大串陶瓷、第一次 MOAB），沒準備的玩家在這裡漏很多。
- 回合結束有固定獎金；擊破每層都給錢，所以**打得好賺得多**。

## 5. 支援與經濟
- **支援塔**本身不太打人，但給周圍的塔加速、加範圍、**給偵測**、或讓它能打鉛。
- **經濟塔**（香蕉園）把現在的錢換成之後更多的錢。
- 賣塔退回大約 70%。

## 6. 英雄
- 每局只能帶一位英雄，**自己會升級**（隨回合／經驗），等級到了自動解鎖技能。
- 英雄會讓某一類塔變強（強化特定組合）。

## 7. 對我們有用的設計重點
1. **「誰能處理什麼」**：屬性 × 傷害類型做出必要的搭配，而且每種屬性都要有 2～3 種解法（基本能力、升級路線、支援、主動技能），不能只有一個答案。
2. **路線選擇＝定位選擇**：同一位同事升級時二選一，同一個人可以是單體或範圍、看得到隱形或能破甲。
3. **主動技能留給危險時刻**：冷卻長、效果大。
4. **新屬性的教學節奏**：先少量、再混編、最後檢查點。
5. **大目標死亡吐出小兵**：頭目或大型敵人倒下時，後面還要有人接。
6. 不學的：氣球一層包一層（我們的敵人是一個人，不是氣球）、猴子知識（養成是長期留人機制，使用者不要）、付費英雄。
