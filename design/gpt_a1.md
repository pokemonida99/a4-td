我最推薦把這款做成「同事守住下班時間」：敵人把加班、公文與客訴一路送往打卡機，玩家靠隨機叫來的同事組成防線。這樣能保留抽人、佈陣、合併的爽感，也能讓《上班旅人》的角色關係成為主角。

## A. 遊戲名稱：三個候選

| 名稱 | 方向 |
|---|---|
| **《上班旅人外傳：準時下班防衛戰》** | 最推薦。一眼看懂目標，容易宣傳，也適合後續追加不同分公司地圖。 |
| 《上班旅人外傳：本日拒絕加班》 | 厭世感最強，適合偏喜劇、角色吐槽多的版本。 |
| 《上班旅人外傳：最後一道簽核》 | 奇幻戰役感較強，能把頭目包裝成逐級闖關的主管。 |

以下以《準時下班防衛戰》為主案。

## B. 核心循環

### 推薦版：守住打卡機

**一局的故事：距離下班只剩最後一輪工作，奧客總經理卻決定臨時加開會議。**

| 項目 | 設計 |
|---|---|
| 自動恢復資源 | **人力額度**：每秒 +1，上限 30；每次「緊急調派」消耗 10。 |
| 擊倒獎勵資源 | **部門預算**：擊倒敵人、完成波次取得，用於調位與購買本局補給。 |
| 隨機召喚 | 按「緊急調派」，從本局出勤名單隨機叫來一位同事，再點空格配置。 |
| 塔格 | **應變工位**：地上以銅色編號標記的臨時值勤位置，旁邊放矮公文櫃或工作箱。 |
| 同名合併 | **職級核定**：兩位同名、同職級同事合併成更高職級；保留玩家選定的位置。 |
| 職級上限 | I → II → III，最多三級。合併不改變職業，也不抽成別人。 |
| 生命 | **下班底氣**，初始 20。 |
| 敵人的終點 | **打卡機**；敵人抵達就追加工作，扣除下班底氣。歸零代表全員被留下加班。 |

**每局從 16 人中選 6 位出勤**，提供預設隊伍，讓新玩家直接開打。六人只是抽取池，不做下方五張手牌。

基本循環：

1. 開波，敵人沿走道進攻。
2. 人力額度持續恢復，玩家緊急調派同事。
3. 點空工位上場，或把新同事與場上同名同職級合併。
4. 擊倒敵人取得部門預算，處理調位、道具與下一波準備。
5. 累積氣勢，決定何時使用合體技或超級化。
6. 擊敗第 20 波奧客總經理，準時打卡。

幾個必須先處理的操作細節：

- **召喚後可先看人，再選工位**，不用盲猜位置。
- 全滿時仍可召喚到一個「報到中」暫存位；未配置前不能再抽。
- 若暫存同事不能合併，可「轉派支援」退回 5 人力額度，避免卡死。
- 連續三次沒抽到場上任何可合併對象，下一抽保證提供一個；前提是抽取池內確實存在可合併對象。
- 點選同事後，只亮出合法合併位置；手機不用精準拖曳。
- 調位消耗少量部門預算，波間提供一次免費調位。
- 三級同事仍可能抽到第二位，可選擇分站守路。

**職級提升的初版數值**可先設為輸出／治療量的 1、1.8、3.2 倍。合併會失去一個站點與覆蓋範圍，因此不會永遠是立即合併最划算。

### 差異較大的替代版：移動式下班接駁車

目標改為**護送員工接駁車穿過分公司園區**。

- 自動資源：**排班點數**。
- 擊倒資源：**交通津貼**。
- 召喚：**臨時補班名單**，隨機叫一位同事上車。
- 格子：接駁車兩側的**防衛席位**。
- 合併：**交接整編**，同名同事升級。
- 生命：**車體耐久**。
- 敵人目的：衝到接駁車旁追加任務、拖住車輛。
- 每五波抵達一站，車輛移動，下一段換地景與進攻方向。

這版特色更鮮明，但會增加車輛移動、鏡頭與多方向戰鬥的製作成本。**第一版建議先做固定辦公室。**

## C. 16 位同事當塔

先訂三條共通規則，才能維持 RPG 定位：

- **坦克不直接堵路**：站在工位上，用近戰範圍攔截與短暫停步控制敵人。
- **同事不會永久陣亡**：部分敵人會施加「疲勞」，每層降低攻速，最多三層；補師可消除。避免玩家因少帶補師而無法通關。
- **弱點直接標在敵人身上**：每隻敵人最多一個弱點，對應屬性傷害 ×1.5，不另做六屬性循環剋制。

| 同事 | 攻擊／支援方式 | 一個辨識度高的特色 |
|---|---|---|
| **小葵 kui／斬** | 中近距離單體斬擊 | 同一目標連斬三次，第三擊重斬；適合放在轉角，持續追打高血量敵人。 |
| **阿傑 jie／暗** | 小範圍暗焰、持續灼燒 | 暗焰使敵人施加疲勞的效果下降；灼燒仍算暗屬性，避免與阿哲混淆。 |
| **Kevin／打** | 近距離扇形盾擊 | 累積數次攻擊後，使範圍內最多三隻敵人短暫停步；不會永久封路。 |
| **小米 mi／光** | 鄰近同事群體回復 | 移除疲勞；沒有人疲勞時，改替附近同事補上一次性的「專注護盾」，擋下一次疲勞。 |
| **Vivi／光** | 範圍應援，低頻光彈補刀 | 每隔一段時間指定附近一位同事為「本月之星」，暫時加攻；優先選輸出職。 |
| **小燕 yan／冰** | 小範圍冰擊、減速 | 連續命中同一目標可短暫凍結；頭目改為較短的額外減速。 |
| **黑輪 heilun／打** | 遠距離單體投擲名片 | 替目標掛上「已成交」，被擊倒時額外取得少量部門預算；同一敵人只結算一次。 |
| **茶茶 cha／光** | 定期送出珍奶補給 | 輪流讓附近同事短暫加速；優先服務尚未獲得珍奶效果的人。 |

| **學姊 senpai／斬** | 遠距離單體精準攻擊 | 用放大鏡標記破綻，讓全隊對該目標的弱點加成暫時提高；同時只能標一隻。 |
| **小蝶 wu／斬** | 短距離迴旋斬＋舞蹈支援 | 固定拍點替周圍同事縮短下一次攻擊等待時間；同名舞蹈效果不疊加。 |
| **老油條 you／斬** | 快速單體攻擊 | 優先補刀低血量敵人，對殘血目標增傷；適合放在終點前收尾。 |
| **鼠仙女 fairy／光** | 召喚物沿路作戰 | 灰鼠衝向敵人造成光傷；棕鼠在指定路段短暫攔截。每位仙女的在場召喚數有上限。 |
| **許許 xu／冰** | 遠距離單體冰藥瓶 | 定期替範圍內疲勞最重的同事解狀態，接著讓其數次攻擊附帶少量冰傷。 |
| **阿哲 zhe／火** | 長直線穿刺 | 火焰槍刺穿同一直線上的數名敵人；直走廊最強，適合處理密集隊伍。 |
| **小安 an／冰** | 短距離冰屬盾擊 | 在射程內預設路點放三角錐，讓經過敵人短暫減速；不改變路線，對飛行無效。 |

**鼠仙女的價值是把影響範圍延伸到工位之外**；召喚物可沿道路前進，但必須有時間與數量上限，不能無限堆鼠。

**Vivi 的價值是提高關鍵工位的效率**，特別適合包住兩三位高職級輸出。戰場上的 Vivi 使用像素角色；介面助手使用半身立繪，不必解釋成兩個角色。

**補師的價值是維持陣形效率**。小米偏群體防護，許許偏單點解狀態與補傷害。兩人都不直接回復下班底氣，避免漏怪後靠補血無限拖延。

屬性與敵人外觀可以建立直覺：

- 紙製公文、木製文件箱：弱火。
- 過熱機械、暴走跑者：弱冰。
- 幽靈加班者：弱光。
- 附和結界、主管話術：弱暗。
- 束帶、觸手類目標：弱斬。
- 機殼、硬殼：弱打。

弱點只用於部分敵人；一般加班大隊可沒有弱點，避免每波都變成配對考試。

## E. 氣勢、合體技、超級化

建議統一使用**一條全隊氣勢，最高 100**，避免手機同時管理多套能量。

氣勢主要由擊倒敵人與完成波次取得，少量由有效控制、治療疲勞取得。後者設取得間隔，不能靠反覆治療刷滿。

| 用途 | 消耗 | 決策 |
|---|---:|---|
| **合體技** | 60 | 解決特定區域或敵群，適合緊急救場與頭目破防。 |
| **超級化** | 100 | 指定一位同事強化 12 秒，適合長時間輸出或撐過高壓波。 |

### 合體技：帶進場前選兩招

不用為所有兩人組合製作技能。首版先做四組，出勤名單符合即可攜帶：

| 組合 | 名稱與效果 |
|---|---|
| 小葵＋阿哲 | **「這案今天結」**：選一直線路段，造成斬／火兩段傷害。 |
| Kevin＋小安 | **「依規定辦理」**：選一段道路架設短暫防線，小兵停步，頭目大幅減速。 |
| 阿傑＋小燕 | **「冷處理，燒到你」**：指定區域冰緩並附加暗焰，持續處理密集敵群。 |
| Vivi＋茶茶 | **「老闆請客」**：全隊清除一層疲勞，並短暫提高攻速。 |

兩位同事都必須在場；發動後有短冷卻，但不消耗角色。職級可提高效果，**不把站在一起當發動條件**，免得陣形被綁死。

### 超級化：強化角色原本的工作

- 輸出：提高傷害，附帶角色專屬強化，例如阿哲多穿透兩個目標。
- 坦克：增加攔截數與控制頻率。
- 輔助：擴大支援範圍、增加受益人數。
- 補師：提高解疲勞頻率，額外提供專注護盾。

金髮金眼沿用 RPG 語言；發光、髮色替換與簡短特效即可，不必重畫全部八格動畫。

**決策核心是：60 氣勢先救眼前這波，還是留到 100，把三級主力推到超級化？** 不再加第三種通用氣勢技，先把這個取捨做好。

## F. 橫向 1280 × 590 版位

採用**左側會議側欄＋右側戰場＋底部指令帶**，與參考圖的森林中央戰場、左方視訊、下方五卡抽塔形成明顯區隔。

| 區域 | 建議範圍 | 內容 |
|---|---|---|
| 左側會議側欄 | x 0～184，整高 | 上方顯示「今日議程」、波次與下班底氣；中段是下一波敵情；下段放 Vivi 小型視訊。 |
| 戰場上緣 | x 184～1280，y 0～48 | 人力額度、部門預算、暫停與倍速；不放擊倒數等低優先資訊。 |
| 地圖 | x 184～1280，y 48～490 | 主要遊戲區，保持中央完整。 |
| 底部指令帶 | x 184～1280，y 490～590 | 左方「緊急調派」與報到中角色，中間放選中同事資訊／合併／調位，右方放氣勢與兩個主動技入口。 |

具體互動：

- 「緊急調派」按鈕約 **144 × 64**，全局固定位置。
- 主要按鈕觸控區至少約 **56 × 56**；主資訊文字以 24～28 px 起做實機測試。
- 主動技按下後，底部顯示「請選路段」，合法範圍直接亮在地面；點空白取消。
- 頭目預告放在戰場上緣的窄條，地面只顯示必要的攻擊範圍。
- 教學、吐槽與敵情都進左側欄，不彈中央對話框。
- Vivi 每次只講一則短句，例如：「本公司鼓勵準時下班，現在請各位證明。」
- 正式畫面用自家「公司通訊」樣式，避免直接仿製 LINE 商標與介面。

底部不做五張卡片，而是**一個調派入口、一個報到位、一張選中同事的議程紙**。操作邏輯更像管理辦公室。

## G. 第一張地圖與視角

### 視角：淺角度 3/4，角色維持正側面

建議使用**能看到地板與少量家具頂面的淺角度 3/4 視角**，不要做標準等角菱形格。

- 地板以橫向與縱深為主，家具正面較多、頂面較少。
- 工位是橫向短平台，角色站在平台前緣。
- 角色腳底加小型接觸陰影，以腳底位置做前後遮擋排序。
- 敵人走路以左右移動為主，轉彎使用短斜向銜接。
- 不要求側面小人長距離朝畫面深處走，也不旋轉角色來假裝有背面。
- 像素主體保持清楚，HD-2D 的光暈與景深放在背景層，不模糊角色。

既有 60 × 117 小人先以接近原尺寸測試，**用工位間距容納角色**，不要先塞滿格子再把角色縮到看不清。

### 第一張地圖：行政部・下班前一小時

場景包含：電梯口、影印區、低隔板、茶水間、會議室玻璃牆，以及出口旁的打卡機。

**路徑採開口的橫向 S 形，主幹道不繞成閉環：**

1. 敵人從右上方電梯口進場。
2. 沿上走廊向左。
3. 在左側影印區轉下。
4. 沿下走廊向右。
5. 最後轉入右側打卡機。

讓敵人主要呈現左右側面，兩段走廊也能共用部分工位射程。上方工位與下方走道之間留出角色頭部空間。

**初版建議 12 個工位，另有 1 個介面暫存位。**

- 6 個一般輸出位：覆蓋單一路段。
- 4 個交會位：射程可碰到兩段道路，但工位彼此不全相鄰。
- 2 個終點位：處理漏怪，覆蓋時間較短。
- 一般遠程射程先以約 180 px 試作；近戰依道路邊緣距離調整。
- 預留一條外送員捷徑，以及一條空拍機航線，兩者在相關波次前才亮出預告。

不要讓每個位置都同樣好；也不要讓一個正中央工位能打完整條路。

## H. 新美術清單與英文提示詞

### 優先新增的素材

| 類別 | 需要新增 | 製作方式 |
|---|---|---|
| 地圖 | 辦公室背景、道路、捷徑入口、打卡機、電梯門 | GPT 生風格稿與背景底圖，再依實際路線整理分層。 |
| 工位 | 空工位、選中外框、合法合併標記、三級職級牌 | 同一底座共用，以銅牌和印章區分職級。 |
| 介面 | 胡桃木框、議程紙、銅夾子、印章、資源圖示、按鈕狀態 | GPT 生材質參考；文字、數值和可互動元件另外製作。 |
| 敵人動畫 | 缺少的左右行走循環、飛行循環、頭目規則特效 | 以既有角色圖為參考生成，再校正像素與格位。 |
| 戰鬥特效 | 六屬性命中、疲勞、護盾、理虧、合併、氣勢滿值 | 優先共用特效，靠形狀與顏色區分。 |
| 主動技 | 四組合體技的短特效 | 重用兩人的半身立繪與既有出招動畫。 |
| 超級化 | 金髮金眼配色、金色輪廓與氣場 | 優先用調色遮罩與共用氣場完成。 |
| 助手 | Vivi 視訊框與少量表情 | 沿用半身立繪，追加說話、無奈、得意表情即可。 |

**先確認敵人素材有沒有走路動畫。** 現有的 ready、wind、act、win 與出招八格不能直接視為行走循環；若缺少，這會是最需要優先補齊的動畫項目。

圖像生成適合協助畫底圖與變體；碰撞路線、動畫幀對齊、文字與 UI 狀態仍要依遊戲規格整理。

### 1. 第一張地圖背景

```text
Create a production-oriented background plate for a landscape mobile pixel-art tower defense game, an office-fantasy comedy set in a Taiwanese corporate administrative department, one hour before clock-out.

Canvas: 1096 x 442 pixels. Use a shallow three-quarter view with mostly front-facing furniture, visible floor surfaces, and restrained perspective. The background must accommodate existing upright side-view character sprites approximately 60 x 117 pixels tall.

Design an open horizontal S-shaped walking route: an elevator entrance at the upper right, an upper corridor traveling left, a short downward turn beside a copy-machine area on the left, a lower corridor traveling right, then a short final turn toward a clock-out terminal near the lower right. Keep the route broad, continuous, visually readable, and unobstructed.

Reserve twelve empty placement areas beside the corridors, with generous vertical clearance for tall character sprites. Do not draw placement pads. Include a restrained office setting with low partitions, filing cabinets, a pantry corner, glass meeting-room walls, fluorescent ceiling light reflections, and warm late-afternoon window light.

Visual style: crisp handcrafted pixel art, selective HD-2D lighting, muted walnut brown, warm ivory, oxidized brass, gray-green office furniture, subtle atmospheric depth only in the distant background. Foreground walking surfaces must remain sharp.

No characters, enemies, interface, text, letters, numbers, logos, pastel gradients, rounded app panels, or decorative objects blocking the route. Keep tall furniture away from the playable foreground.
```

這張作為背景底圖；正式道路遮罩與十二個工位位置由遊戲端固定，不讓生成結果決定碰撞。

### 2. 放塔的格子

```text
Create a single reusable placement-pad sprite for a Taiwanese office-fantasy pixel-art tower defense game.

Transparent background. Asset canvas: 96 x 64 pixels. Show a low, shallow three-quarter-view rectangular emergency workstation base made from dark walnut trim, a worn ivory floor inset, and small brass corner fittings. The pad must clearly support an upright side-view character standing at its front-center anchor point.

Leave the center empty. Keep the object low and flat, with no desk surface, chair, monitor, tall furniture, or object that would hide the character's legs. Add a small blank brass rank plate at the front edge, with no text or symbols.

Use crisp pixel clusters, hard readable edges, restrained highlights, and a palette suitable for a mature office-fantasy RPG. The design should feel practical, slightly worn, and handmade. No soft shadow baked into the asset, no glow, no UI frame, no letters, no numbers, no characters.
```

選取框、合併提示與職級印章另外疊圖，底座只需一套。

### 3. 敵人走路

以下要**附上該敵人的既有圖**再生成：

```text
Using the attached existing enemy sprite as the strict character reference, create a clean six-frame side-view walking animation sprite sheet for a pixel-art tower defense game.

Preserve the exact character identity, costume, proportions, silhouette, outline treatment, palette, and pixel density of the reference. The character faces right in every frame.

Output one horizontal row of six equal cells, each 96 x 128 pixels, total canvas 576 x 128 pixels, on a transparent background. Keep a fixed ground baseline at y = 120 within every cell, and keep the character's horizontal root position consistent. The animation must walk in place without drifting.

Create a seamless walk cycle with clear foot contact, passing poses, alternating leg motion, restrained arm swing, and minimal vertical bobbing. Keep carried props attached consistently and leave enough transparent padding to prevent clipping.

Use crisp pixel art with no antialiasing, blur, motion trails, lighting changes, added effects, text, labels, borders, or cell dividers. Do not redesign the character, change its outfit, add extra limbs, rotate it toward the camera, or crop any body part.
```

左右造型對稱的敵人可以水平翻轉；拿盾、拿卷軸或服裝明顯不對稱的頭目，則另外製作左向版本。

首個可玩版本建議先驗證 **12 工位、6 人出勤、10 波、2 隻頭目、2 組合體技**。確認「抽到誰、放哪裡、現在合不合、氣勢要不要花」四個問題都有趣，再擴充完整 20 波與 16 位同事。
