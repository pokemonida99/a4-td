1. **視角：我同意優先查尺寸，但兩張圖還不足以確定是 `innerHeight`。**

   - 兩張截圖的長寬比幾乎一樣，都是 **2.17：1**；但圖 1 的浮島更寬、更扁，背牆和走道的縱深也明顯縮小。這不像單純「手機螢幕比較寬」，比較像 **3D 畫面的比例、正交投影範圍，或相機狀態不一致**。
   - 圖 1 的 HUD 看起來沒有同等程度的壓扁，因此優先檢查 **3D canvas 與投影**。轉向後取得舊高度確實可能造成這種結果，但前提是它讓「投影長寬比」和「實際顯示長寬比」不一致；**舊高度本身不一定會壓扁畫面**。
   - 建議畫面上暫時顯示這些數值，直接比較兩台：
     - canvas 的 CSS 寬高、實際繪圖寬高。
     - 容器寬高、`innerWidth/innerHeight`、`visualViewport` 寬高。
     - 正交相機的 `left/right/top/bottom`、`zoom`、位置與目標點。
   - 核心驗證：**投影寬高比＝canvas 顯示寬高比**。半解析度應讓寬、高一起乘 **0.5**；DPR 改變清晰度，不該改變物件比例。用一顆暫時測試的球也很好判斷：變橢圓就是比例問題。
   - 尺寸更新建議以 **canvas 容器的實際矩形**為準；轉向後持續確認約 **300～500 ms**，尺寸穩定再完成配置，避免只讀一次轉向事件當下的數字。

   **正常畫面的鏡頭，我會從這組開始調：**

   - **俯角 42°、水平轉角 12°、可見世界寬 37 單位**。這裡俯角指「從水平面往下看」；若程式使用其他角度定義，要先換算。
   - 可調範圍：俯角 **40～44°**、水平轉角 **10～14°**、世界寬 **36～38**。
   - **34° 可以做漂亮的模型展示，但對這張有桌子、隔板、三條走道的塔防偏低。** 從 34° 提到 42°，地面縱深投影約增加 **20%**，通常比單純放大更有幫助。
   - 水平轉角從 18° 降到 12°，能減少左右工位的斜向重疊，也讓右側電梯區少吃一些縱向空間。
   - 人物完整身高目標為螢幕高度的 **8～10%**；一般戰鬥不要低於 **7%**。以兩張圖約 2.17：1 的比例，以上鏡頭起始值大致落在合理範圍。
   - 浮島目標佔畫面寬 **78～85%**、高 **75～82%**，中心約在畫面 **X＝50%、Y＝51%**。這些是驗收目標，最後用包含背牆的實際邊界微調。
   - **不要額外加固定大黑邊。** 保留上方約 **10～12%** 的安靜區放 HUD；右下預告縮小。選單開啟時才用下方 **24～28%** 的抽屜，並把選取工位移到不被遮住的位置。

   **遮擋處理依這個順序做：**

   - 先把隔板降到人物身高的 **30～40%**，約 **0.6～0.8 單位**；桌面約 **0.65～0.75 單位**。
   - 再提高俯角至 **42°**。
   - 走道淨寬至少為敵人身體寬的 **1.5～1.8 倍**，先檢查中間走道是否真的不足，再改地圖。
   - 最後才加局部透明：敵人被遮住時，相關隔板淡到 **25～35% 不透明度**，過渡 **120～180 ms**。桌面和整排家具一起變透明會讓模型散掉，不建議當第一招。

2. **清楚好懂：保留夜景，讓「可操作資訊」自己發光。**

   - **先提高辨識底線，再增加燈光。** 把目前完全吃黑的地面、敵人暗面抬亮約 **15～25%**；保留桌燈、電梯和打卡機為最亮區域。避免直接把整張圖曝光拉高。
   - 走道改成比工位區亮 **15～20%**、偏冷灰藍的材質。三條橫向走道都保持連續可見，紙張、裝飾不要切斷路徑。
   - 沿走道每隔 **1.5～2 單位**放一個低亮度方向記號。平常淡，備戰時用一顆光點花 **2～3 秒**從電梯跑到打卡機；轉彎位置必須有箭頭。
   - 敵人加 **1～2 CSS px** 的輪廓，或細亮邊搭配腳底接地圈。這些資訊最好在半解析度處理後繪製，避免被抖色吃掉。
   - 屬性圖示放在敵人頭頂，約 **16～20 CSS px**；特性只顯示一個主要圖示。不要讓玩家靠衣服顏色辨認水火風。
   - 平常血條只在受傷、被選取或精英出現時顯示。傷害數字只保留暴擊／剋屬／大傷害，最多同時 **6～8 個**，降低混亂。
   - 空工位使用低亮度青色圈與明確的「＋」。圈的可見尺寸至少約 **28～36 CSS px**，實際點擊區至少 **44～48 CSS px**。
   - 選中工位時，其他空位標記降到 **30% 亮度**；顯示所選同事的射程，並把射程內的**走道路段**提亮。比只畫一個被桌子遮住的圓更容易理解。
   - 移軸景深把 **三條戰鬥走道都納入清晰帶**，模糊集中在遠牆和浮島外緣。美術可以糊，敵人、格位、射程與文字不要糊。

3. **一個晚上，我會依序做這 6 項；時間不夠就停在前 3 項。**

   - **① 先重做波次壓力與經濟，這是目前最需要的。**
     - 亂買也有 98% 勝率，代表策略差異還沒有實際代價；新增技能前先修這件事。
     - 若現有模擬包含完整戰鬥機制，先把第 **4～8 波威脅預算提高 20～30%**，第 **9～12 波提高 30～40%**。威脅預算要計入血量、數量、速度與特性，不要全部只加血。
     - **先維持擊殺總收入不變**；增加敵人數量時分攤賞金，避免越加怪，玩家越有錢。
     - 經濟目標：起始 **160 元**能買 **2 位基本同事＋1 次便宜升級**；第 4 波約有 **4～5 位**，第 8 波約 **7～9 位**，最後通常是 **8～10 位加升級**，而非必定塞滿 12 位。
     - 用相同的 **20～30 組種子**比較策略。普通難度的調整目標可先設為：會配隊約 **80～90% 勝**、亂買約 **35～55% 勝**。這是調參方向，不是保證值。

   - **② 用「兩種敵人互相掩護」製造選擇。**
     - 第 1～3 波每波只教一件事；第 4 波起加入混編，每波最多 **2 種主要特性**。
     - 建議三組先做：
       - 重甲＋快敵：慢的吃火力，快的趁空隙突破。
       - 幽靈＋普通敵：要求至少一個魔法輸出來源。
       - 回血敵＋少量控制敵：要求集中輸出或保護關鍵同事。
     - 若目前沒有護甲公式，重甲先用 **物理傷害減免 40%**；回血敵每秒回 **最大生命 1%**，受傷後 **2 秒**暫停回血。
     - 麻痺／冰凍先控制在 **1～1.5 秒**，同一同事解除後 **4 秒免疫再次控制**，避免整段時間無法操作的挫折。
     - 幽靈首次出場前一波就預告，第一組只佔該波 **15～20%**。

   - **③ 讓升級與剋屬真的需要取捨。**
     - 今晚先保留 **×2／×0.5**，不要同時改相剋與所有敵人數值，否則很難知道哪個調整有效。
     - 每波主要屬性佔 **60～70%**，其餘混其他屬性；避免一位剋屬同事包辦整波。
     - 同事升級先抓：二級增加約 **35～45% 單體 DPS**，三級再增加 **40～50%**；範圍、貫穿、緩速等功能要計入價值，不能額外免費附送完整增傷。
     - 水彈先試 **緩速 25%、持續 1.2 秒、不疊加、刷新時間**。風槍最多穿 **3 個**，後續目標傷害為 **70%、50%**，避免直線走道讓它無條件最強。

   - **④ 加提早開波獎勵，讓熟練玩家主動冒險。**
     - 每波結束提供 **12 秒**備戰倒數。
     - 第 1 波由玩家手動開始；後續可提前開波，每剩 **1 秒獎勵 1 元，上限 10 元**。
     - 今晚先限定「上一波清完才能開」，省掉重疊波次的控制與平衡成本。
     - 獎勵直接顯示「現在開波：＋8」，讓等待與賺錢形成明確取捨。

   - **⑤ 只加一個主動技能：「主管巡場」。**
     - 效果：所有同事攻速 **＋30%，持續 5 秒，冷卻 35 秒**。
     - 用於快敵衝線、精英接近終點或火力空窗；有清楚的使用時機。
     - 按鈕至少 **52×52 CSS px**，不用再選地點。先不要做全畫面清怪，容易把剋屬與配置的重要性沖掉。

   - **⑥ 用兩個難度保留輕鬆玩家。**
     - **普通**使用前面調好的基準；**加班地獄**先只改為敵人血量 **×1.2**、起始資金 **140 元**，賞金維持相同。
     - 普通模式前 **3 波**可免費撤回配置；之後維持賣出退 **60%**。降低新手第一次誤放就崩盤的機率。
     - 先不要做第三種難度，也不要為不同難度各維護一套波次。

   **今晚不要做：**新增同事、更多屬性、裝備／天賦樹、隨機永久成長、重畫路線、多個主動技能。你已有 16 位同事與多種特性，缺的是現有選擇之間的壓力與回饋。

4. **介面／上手：手機最容易卡住的是「點不中、看不懂差異、選單擋住現場」。**

   - 卡片不要只列攻擊力與攻速。第一層顯示：**名字、價錢、屬性、用途一句話**，例如「水彈｜緩速單體」「風槍｜直線穿透」。詳細數值點開再看。
   - 「攻速」避免只寫 **1.2**；明確標成「每秒 **1.2 次**」或「每 **0.8 秒**攻擊」。同時提供估計單體 DPS，範圍傷害另外標示。
   - 16 張卡不要全部排成一條長橫列。先提供 **輸出／控制／支援**三個分類，每屏約 **3～4 張**；已派駐者顯示「已上場」，買不起的保留可閱讀性並寫「差 20 元」。
   - 點空位後先選同事，顯示模型預覽、射程和價錢，按一次「派駐」完成。**雙階段確認用在派駐，升級不必每次再跳對話框。**
   - 普通模式開啟派駐／升級抽屜時自動暫停；關閉後恢復原速度。橫向手機同時滑卡片與看戰場，操作負擔很高。
   - 工位點擊判定用擴大的地面區域，選取最近的可用工位；不要要求點中桌子模型。拖動超過約 **8～12 CSS px**就當作滑動，避免滑卡片時誤買。
   - 下一波預告顯示「**總數＋主要屬性＋主要特性**」，例如「12 名｜火 8／風 4｜重甲 3」。你現在的「還有 3 個」旁邊仍出現「×8」，容易把剩餘數與整波總數混淆，必須加標籤。
   - 常駐相剋表縮成可點圖示；選同事時才顯示「對下波主要敵人 **傷害 ×2**」。光闇互剋與幽靈免疫物理，要在相關情境直接提醒。
   - 教學分 **3 次、每次只做一件事**：
     - 第 1 波：派駐一位同事，亮出電梯到打卡機的路徑。
     - 第 2 波：預告主屬性，提示一個有利選擇，讓玩家自己買。
     - 第 3 波：提示升級或技能，使用一次後收起。
   - 提示文字每次約 **15～25 字**，可跳過；不要開場介紹全部系統。
   - 驗收至少看 **844×390** 與 **740×360 CSS px**：正文 **16～18 px**、次要文字至少 **14 px**、主要按鈕高度 **48 px**，並避開瀏海與底部手勢區。

   - **如果今晚只能先改三件事：修正投影尺寸一致性、改成 42°／12° 的鏡頭起點、調整第 4 波後的威脅與收入。** 這三項最直接影響「看得懂」和「配隊有沒有意義」。
